One haiku about debugging — three lines in strict 5-7-5 syllables, at most 200 characters, plain text. The program writes it to `/output/entry.txt`.

```
A breakpoint blinks red
the log says nothing happened
the bug wore my face
```

## Run it

```sh
python3 main.py
```
